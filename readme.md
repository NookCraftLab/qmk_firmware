# QMK Firmware - NookCraftLab 维护分支

这是 NookCraftLab 维护的 QMK Firmware 分支，用于客制化键盘固件开发。

## 关于

本仓库基于上游 [QMK Firmware](https://github.com/qmk/qmk_firmware)，针对 NookCraftLab 的键盘固件项目进行了适配和修改。

## 上游来源

- 上游仓库：https://github.com/qmk/qmk_firmware
- 许可证：GNU General Public License v2.0

## 修改内容

本分支针对以下方面进行了适配：
- CH585 芯片平台支持
- Vial 改键功能集成
- 蓝牙无线功能适配
- 其他客制化键盘相关功能
